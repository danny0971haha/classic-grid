# Artifacts

`historical/classic-v0.2-checkpoint-e-results.non-authoritative.json` is the rejected Checkpoint E campaign file. Its `E-01`..`E-30` `result="PASS"` values were synthesized before the Node test process ran. It is kept only as a historical record and is **not** machine evidence.

Authoritative Checkpoint E evidence is the GitHub Actions artifact `classic-v0.2-checkpoint-e-results` generated by `tools/checkpoint-e-evidence.ts`:

```text
npm run evidence:checkpoint-e
npm run evidence:checkpoint-e:verify
```

The generator parses TAP from the live Checkpoint E suite. It does not fill PASS from `CASE_IDS`. Do not check in a generated results JSON that claims the current commit SHA.
